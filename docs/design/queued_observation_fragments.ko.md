# 다음 관찰 조각 통합 대기열

## 우사기 EP6 팔 내림 보강
현재 v5 런타임은 A→B 후 숨김과 별도 정지 C를 유지합니다. 기존 미확인 기록은 당시 검증 범위로 보존합니다.

후속 실제 영상 표본에서는 D(닫힌 입·낮은 팔 벌림)→E(팔을 비스듬히 아래로)→C(팔 내림)를 확인했습니다. D/E의 파생 정적 원화와 공통 등록은 제한 시각 검수를 통과했습니다. [영상 출처](https://www.tiktok.com/@chiikawa562/video/7448691479851175214).

다음 통합은 이 별도 관찰 조각만 명시 호출하는 한 번의 D→E→C 순서를 검토할 수 있습니다. 재생 리듬은 제작 UI 타이밍으로 표시해야 하며 영상의 정확한 속도를 주장하지 않습니다. B→D 하강·몸기울임 전 구간, 정확한 접지 시각, 원본 모든 연속 프레임은 여전히 확보되지 않았습니다. 따라서 A→B→D→E→C를 완전한 자연 점프로 이어 붙이거나 중간 프레임/접촉을 보간해서는 안 됩니다.

등록 시 주의: 개별 bbox를 같은 높이로 늘리지 않고 검수된 source crop과 각 등비 크기/공통 stage anchor를 사용합니다. D/E와 기존 C 사이 실제 브라우저 전환, 학습 입력 우선 취소, 기본 우사기 독점/복원, 동작 줄이기·일시정지, 안전 무대 검수를 다시 통과해야 합니다.

이 대기열 자체는 런타임 활성화나 원작 완전모션 registry 승인이 아닙니다. v5 A→B 검증 기록과 새 팔 내림 표본은 서로 다른 범위의 근거로 남깁니다.

## v6 후속 상태
위 D→E→C 보강은 별도 명시 호출 조각으로 v6에 통합했습니다. v5 A→B 검수 기록은 그대로 보존하며 미확인 B→D 접지/하강을 연결하지 않습니다. 자세한 범위와 구현은 `v6_observed_fragments.ko.md`를 참조하세요.
