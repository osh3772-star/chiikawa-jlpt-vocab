# v6 관찰 조각 보강

v5 안전 hotfix를 보존한 후속 구현입니다. 원작 완전 동작 registry 활성화는 여전히 0이며 자연스러운 최종 6종 애니메이션의 완성 선언이 아닙니다.

## 추가한 제한 표현
- **우사기 D→E→C**: 새 영상 표본의 낮은 팔 벌림→비스듬한 팔 내림→팔 내린 자세만 별도 버튼으로 한 번 표시합니다. 기존 A→B와 자동 연결하지 않습니다. B→D 하강·몸 기울임의 전 구간, 정확한 접지 시각은 미확인입니다. 새 관찰은 옛 미확인 기록을 삭제하는 대신 보강합니다.
- **시사 Open→Closed**: 같은 원화 캔버스/고정 UI 컵/공통 원점에서 입 열림→닫힘 두 정지 상태만 표시합니다. 원작에서는 쿠리만쥬가 잔을 든다는 설명은 유지합니다. 줄기·병·몸·액면 움직임, 컵 주고받기나 전체 붓기 동작을 새로 만들지 않습니다. 별도 대각 원화는 이 버전에 포함하지 않습니다.
- **랏코 Open→Closed**: 컵·크림·목도리 위치를 유지한 상체 두 표정입니다. 오른쪽 비대칭 특징을 뒤집지 않습니다. 하체·마시기·컵 내리기는 없으며 하단 창으로 상체 표현임을 드러냅니다.

650ms 간격은 **제작 UI 리듬**이며 정확한 원작 시간/프레임 속도가 아닙니다. 모두 기본 꺼짐·명시 호출·한 번 재생 뒤 마지막 자세 유지입니다. 일시정지/시스템 동작 줄이기에서는 첫 정지 자세만 표시합니다. 자동 반복·역재생·모핑·미관찰 중간 자세·몸 전체 흔들기 대체는 없습니다.

## 구현 계약
`observed_fragments.py`는 `observed-fragments.json`의 해시·크기·crop·등비 scale·stage 위치·순서·범위를 고정 검증합니다. `observed-pose-fragment.mjs`는 우사기 보강/랏코의 동일 image-DOM 상태기계를 제공합니다. CSS crop은 원본 PNG 픽셀을 다시 쓰지 않습니다. 랏코 공통 150×110 상체 창은 기존 검수 등비 스케일/동일 offset에 하단 창틀을 적용합니다.

`shisa_two_static_gate.py`는 두 원화의 검증이 모두 끝나기 전 dataURI를 반환하지 않습니다. `shisa-two-static-controller.mjs`는 기존 정적 receiver를 그대로 사용하며 하나의 캐릭터 독점권과 취소 가능한 UI 타이머만 추가합니다.

기존 학습 입력·숨김·Escape·페이지/창 변경·다른 미리보기·접힘 취소를 재사용합니다. 우사기의 두 관찰 조각은 같은 image/rail을 공유하므로 늦은 decode가 다른 조각을 덮거나 새 소유권을 해제하지 않는 회귀 검사를 별도로 추가했습니다. 캐릭터 관리 컨트롤에 초점이 있는 방향키는 학습 이동/채점으로 전파되지 않습니다.

## 재현
```sh
python build_html.py
python build_preview.py
node --test tests/*.test.mjs
python -m unittest discover -s tests -p 'test_*.py'
```

단일 offline HTML 빌드는 유지합니다. 원본 PNG 재압축/크기 변경 없이 외부 자산 빌드 모드를 추가하는 방안은 이후 웹 로딩 최적화 단계의 별도 과제이며 여기에 포함하지 않습니다. `docs/index.html` 배포본은 이 소스 변경만으로 바뀌지 않습니다.

## 화면 자격 안전 후속을 포함한 발행 묶음
이 통합 묶음은 `viewport_eligibility.ko.md`의 화면 밖 자동 대상 제외를 함께 포함합니다. 최종 검증은 두 builder 실행 후 Node 223개 + Python 50개, 총 273개 PASS입니다. 원작 완전 동작 registry 활성화는 여전히 0입니다. 개별 관찰 조각과 화면 자격 후속의 실제 검수/미확인 범위는 각각의 review JSON에 분리 기록했습니다.
