핵심 판정
- 카니 요청은 공식 표기 古本屋(헌책방)로 정규화한다. UI 후보 표기: 카니 · 古本屋. カニ를 古本屋의 일본어 독음으로 쓰지 않는다(古本屋=ふるほんや).
- パジャマパーティーズ는 한 캐릭터의 색상 스킨이 아니라 みどり·ぴんく·むらさき·しろ 네 멤버의 그룹이다. 그룹 ID와 네 member ID를 분리한다.
- くりまんじゅう의 핵심은 미식가·남을 돌보는 성향. 술만으로 성격을 축소하지 않는다.
- 세 대상 모두 공식 신장(cm), 정확한 나이, 동물 종, 수치화된 키 비율은 이번 공식 자료에서 확인하지 못했다. UNKNOWN으로 유지한다. 상품 치수는 신장이 아니다.
- 실제 공식 정지 이미지 11개(프로필 3개, 회차 8개)를 직접 눈으로 대조했다. 영상은 보지 않았다. 모든 동작은 HOLD_VIDEO_REQUIRED이며 정지 자세만 STILL_REFERENCE_ONLY이다.

1. 카니 / 古本屋
공식 확인: 헌책을 판다. 모몽가에게 받은 게 머리띠를 착용한다. [S1]
외형 직접 관찰: 둥글고 아주 옅은 살구분홍 몸, 더 짙은 분홍 머리띠와 두 개 집게 실루엣, 분홍 볼, 짧은 팔다리. EP341에는 이마 위 분홍 띠, 눈·눈썹·열린 입·분홍 볼이 보인다. 머리띠 집게는 생물학적 귀나 팔이 아니다. [S2,S6]
관계: 모몽가가 머리띠를 주었다는 사실은 프로필로 확인. 성우 인터뷰는 모몽가에게 끌리는 마음과 돌봄·용기라는 해석을 말한다. 이것을 연애/연인/상호 애정 확정으로 승격하지 않는다. [S1,S5]
회차 정지 증거: EP340 「ふたつ／ともだちにあげる」는 회색빛 얼굴에 분홍 집게 두 개가 보이는 클로즈업. EP341 「カニ／カニあいさつ」는 분홍 古本屋와 모몽가의 작은 삽입 이미지. 이것만으로 선물 전달 동작, 집게 개폐 순서, 인사 왕복, 웃음 타이밍은 알 수 없다. [S6]
동작 조사 후보: EP341의 게 머리띠 인사 구간. 정확한 출연자/집게 움직임/팔 움직임/전후자세를 실제 영상에서 나누어 관찰해야 한다. 헌책 넘기기·책 건네기는 직업만으로 만들어 넣지 않는다.
작성 UI 후보(몸동작 창작 아님): 사용자가 선택하면 학습영역 밖 고정 cameo를 표시. 추후 영상 확인된 인사 조각만 클릭에 연결. 학습카드를 물리적인 책으로 취급하거나 카드를 가져가는 연출 금지.

2. 파자마 파티즈 / パジャマパーティーズ
공식 확인: 포셰트의 갑옷이 만든 잠옷을 입고 노래·춤을 선보이는 그룹. 네 멤버 이름이 공식 성우 안내에 개별 표기된다. [S1,S3]
멤버별 정지 식별(EP144 기준):
- みどり: 연두색 잠옷, 머리 위 여러 작은 돌기, 오른쪽으로 보이는 짧은 꼬리; EP145에서는 단독 정면, 양쪽 팔이 올라 있고 음표가 주변에 있다.
- ぴんく: 분홍 잠옷, 양쪽 둥근 작은 돌기.
- むらさき: 연보라 잠옷, 양쪽 작은 돌기.
- しろ: 흰 잠옷, 위쪽 한 개 뾰족한 돌기.
네 멤버 모두 청록회색의 타원형 얼굴 영역, 짧은 팔다리, 앞면 단추가 보인다. 회색 얼굴에 치이카와식 눈·입을 임의로 추가하지 않는다. 색만으로 식별하지 말고 이름/실루엣도 유지한다. [S2,S6]
관계: 네 명은 그룹 멤버. EP155 정지 사진에는 네 명 외에 잠옷을 입은 치이카와·하치와레·우사기가 함께 보인다. 이 세 명을 원래 네 명의 별칭/기본 멤버/색상변형으로 합치지 않는다. EP155의 세 멤버 얼굴에 있는 X 형태도 기본 외형으로 고정하지 않는다(특정 장면 상태). [S6]
회차·자료 충돌: 공식 뉴스 제목은 첫 등장 144화, 본문은 134화라고 쓴다. 공식 회차 목록은 EP144=「パジャマパーティーズ①」, 방송사 인터뷰는 144–155화의 노래/춤 시리즈라고 확인한다. 다만 EP133 「しじみ／パジャマのつどい」 정지 이미지에도 네 잠옷 인물이 보인다. 따라서 '이 외형이 처음 등장한 것은 144화'라고 단정하지 않는다. 안전 표기는 '파자마 파티즈 편은 144–155화'. [S3,S4,S6]
동작 조사 후보: EP145 みどり 단독 공연, EP144 네 멤버 공연, EP155 합동 무대. 정지 사진의 음표/팔 위치는 춤의 박자·진폭·안무·발 디딤 증거가 아니다. 인원수 때문에 네 명 동시 모션을 자동 허용하지 않는다.
작성 UI 후보: 멤버를 개별 선택할 수 있는 그룹 하위 항목. 첫 단계는 한 멤버 정지 cameo; 추후 확인된 단독 동작만 1명 강조 제한으로 사용. 그룹 장면은 별도 배치/안전영역 검토 전 보류. 원곡·가사·성우 음원 자동재생 없음.

3. 쿠리만쥬 / くりまんじゅう
공식 확인: 미식가이며 남을 잘 돌본다. 방송사 프로듀서가 술을 마시는 캐릭터라고 명시한다. 이름을 '栗饅頭'로 임의 정규화하지 않고 공식 히라가나를 사용한다. [S1,S4]
외형 직접 관찰: 크림색/옅은 노랑 몸, 머리 위 넓은 갈색 타원형 무늬, 옆으로 작은 귀, 분홍 볼, 짧은 팔다리. EP035에서 갈색 머리무늬, 눈 사이 주름, 열린 입·치아, 손에 든 캔이 보인다. 캔의 음료 종류는 이 이미지로 확정할 수 없다. 프로필 아이콘의 파란 컵도 기본 신체 일부가 아니다. [S2,S6]
관계: '돌봄 성향'은 누구에게나 같은 상호작용을 한다는 뜻이 아니다. 시사의 법적 보호자/친척/스승이라고 쓰지 않는다. 이번 연구로 둘의 정확한 관계 표현·개별 동작은 승인하지 않는다.
회차 증거: EP035 「くりまんじゅう／乗りマンボー」 클로즈업은 마신 뒤 표정처럼 보이지만 정지 이미지뿐이므로 실제 마시기/내쉬기 순서를 관찰했다고 하지 않는다. EP018에 첫 등장한다는 공식 안내는 있지만 해당 회차 썸네일은 치이카와·하치와레만 보인다. 따라서 EP018 썸네일은 쿠리만쥬 외형 증거가 아니다. [S6,S7]
동작 조사 후보: EP035의 캔·표정 구간. 들기/마시기/내쉬기/내리기의 어느 조각이 실제 보이는지 따로 관찰. 취한 비틀거림·트림·음주 강요 등은 새로 만들지 않는다.
작성 UI 후보: 사용자가 직접 쉼/캐릭터 버튼을 누를 때 정지 cameo 또는 추후 검증된 제한 동작. '알아요' 보상이나 연속학습 음주 보상으로 연결하지 않는다. 앱에서 음료를 차로 바꾸면 원작 장면이라고 주장할 수 없으므로 임의 치환도 금지.

공통 제작 게이트
G0 신원: 이름/그룹/멤버 매핑과 공식 근거를 먼저 고정.
G1 외형: 정면 기준 이미지·눈/입/무늬/소품 마스크·보이는 방향만 아트 지시서에 고정. 공식 색상표는 미확보; 추출 RGB는 해당 파일의 관측값이지 공식 Pantone/브랜드 HEX가 아니다.
G2 동작: 원본 URL, 실제 관찰한 구간, 타임스탬프 성격, 연속 자세 순서, 가림/누락, 관찰자 기록 필요. 회차 요약·프로필·정지 상품으로 통과 불가. 실제로 관찰하지 않은 귀 지연·꼬리 후행·준비·복귀·역재생 연결 금지.
G3 설계: 검증 몸동작과 작성 UI 트리거/위치/확률을 분리. known/unknown은 자기신고지 정오답 아님. 실패/실망 반응 연결 금지.
G4 검수: 새 아트는 허가된 다음 단계에서만 생성하고 기준 이미지와 옆에 놓아 검수. 크기/성격이 다르면 기존 6명 재색칠로 때우지 않음.
G5 구현: 모든 입력은 연출 전 처리; 카드/버튼/포커스 안전영역 비침범; off와 reduced-motion 정지대체; 숨김/취소 시 즉시 중단. 본 문서만으로 배포 허가하지 않음.
