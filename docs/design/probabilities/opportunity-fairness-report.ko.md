# Eligible 시간 기반 공정성 실험 결과

**설계 전용. 아트/런타임 변경 없음.** 정상·중단 조건 각각 3정책×20seeds×6시간, 승인0 별도 20seeds×6시간: 총 140회 가상 실행(840시간). 샘플 시간 단위는 0.5초이며 숫자는 UX 가정이다.

정의와 안전 계약은 `opportunity-fairness-design.ko.md`, 원자료는 `opportunity-fairness-results.json`, 재현은 `python docs/design/probabilities/simulate_opportunity_fairness.py`를 참조한다. 결과 SHA-256은 실행 스크립트와 대조했다.

기준 A에서도 draw 기회 대기는 최장 26초였으므로 이전의 긴 무실행이 곧 기회 박탈은 아니었다. 정상 C는 랏코의 eligible 행동 미선택 최장을 963.5→391.5초(약59% 감소)로 줄였고 중단 C는 844→375초로 줄였다. 이는 유한 표본 최댓값이지 시간 상한 보장이 아니다.

기회 cap이 4초 또는12초여도 공유 슬롯을 기다린 시간은 더해진다. C의 최대 기회 대기 26.5초는 기준보다 0.5초 길었다. 다른 캐릭터의 지연을 숨기지 않으며, 이 표본에서 지속적 독점은 관찰되지 않았지만 모든 실행에 대한 수학적 공정성 증명은 아니다.

## 4. 안전 검증과 권고

- 승인0+중단+C 시나리오: 여섯 캐릭터의 draw=0, 시작=0. 승인 없는 행동을 오래 기다렸다는 이유로 선택하지 않았다.
- 모든 정책에서 시작 시 cooldown/반복/외부 보호/단일 슬롯 assert 통과. 실제 종료 후20초보다 이른 재시작도 별도 확인했다.
- 학습·hidden·pause·reduced·drag·resume 보호 구간의 eligible age는 정지한다. 중단은 현재 actor를 취소하고 복귀 quiet를 우선한다.
- 실제브라우저 입력 누락·pointer capture·카드 가림·원작 충실성·자연스러움은 미검증이다. 이 표본은 정책 비교 근거이지 production 승인 근거가 아니다.

**권고:** C를 다음 승인 아트가 마련됐을 때 비교할 실험 후보로 유지한다. 기회 기반 보정은 긴 eligible 침묵을 완화하면서 평상시 비율을 건드리지 않는 장점이 있지만 시간당 비율은 바뀐다. 현재 앱은 변경하지 않는다. 120초/4초 수치와 +1.36pp 전체 움직임 증가가 학습에 적절한지는 시각 QA로 판단해야 한다.
