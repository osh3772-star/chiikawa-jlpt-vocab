치이카와 캐릭터 쌍 상호작용 연구와 설계
2026년 10월 24일

결론
첫 쌍은 치이카와와 하치와레의 함께 책 또는 카드 보기로 제한한다. 두 캐릭터의 개별 동작 QA가 통과해도 곧바로 활성화하지 않는다. 쌍 전용 아트, 양쪽 반응, 예약과 취소, 학습 영역 비침범을 추가 검증해야 한다. 현재 쌍 구현 및 활성화는 모두 보류다. 기존 개별 원작 모션 활성 수 0이라는 전달된 게이트를 변경하지 않았다.

2. 치이카와와 우사기

3. 하치와레와 우사기

7. 모몽가를 반드시 쌍에 끼워 넣지 않는다

설계 후보 순서
A 함께 살펴보기 — 치이카와와 하치와레
상태: 가장 먼저 스토리보드로 검토할 후보. 구현 잠금.
트리거: 사용자가 학습을 멈춘 뒤 휴식 영역에서 함께 보기 선택. 오답 자체는 자동 트리거가 아니다.
각색 시퀀스: 서로 바라보기 → 하치와레가 빈 장식 카드를 가슴 높이로 보여줌 → 치이카와가 옆에서 시선과 표정으로 반응 → 각자 휴식 자세. 원작 카드가 학습 카드로 바뀐 각색임을 기록한다.
서로 같은 박자 점프 금지. 카드에는 정답·힌트·가짜 일본어를 넣지 않는다. 원작의 공유 카드 접촉을 그대로 구현하려면 두 앞발과 카드의 겹침 프레임이 추가로 필요하다. 첫 버전은 비접촉으로 설계한다.
필수 아트: 양쪽 안쪽 방향 시선, 하치와레 두 손 카드 유지, 치이카와 관찰/작은 미소, 거절 시 중립 복귀, 각각의 복귀 자세, 빈 카드. 스크린샷은 제작용 에셋이 아니다.

B 나란히 쉬기 — 치이카와와 우사기
상태: 두 번째 검토 후보. 구현 잠금.
트리거: 사용자가 휴식 종료를 아직 누르지 않은 명시적 휴식 화면. 정답 연속 횟수로 강제하지 않는다.
각색 시퀀스: 안전 간격으로 자리 잡기 → 우사기의 먼저 끝내는 짧은 먹기 반응과 치이카와의 기다리는 표정을 구분 → 각자 중립. 뜨거움/땀을 공부 실패의 벌처럼 사용하지 않는다. 실제 음식 전달이나 빼앗기 없음.
필수 아트: 별도 컵/손/입 실루엣, 우사기 입 변화와 회복, 치이카와 기다리기, 겹치지 않는 두 자리. 원작 상품 로고와 음원은 복제하지 않는다.

C 짧은 인사와 반응 — 하치와레와 우사기
상태: 삼인 장면의 각색임을 표시한 보류 후보.
트리거: 휴식 영역에서 사용자가 선택했을 때만. 서로 가까워졌다는 이유만으로 실행하지 않는다.
각색 시퀀스: 우사기 작은 점프 조각 → 하치와레 관찰 자세 → 양쪽 복귀. 하치와레의 고유 반응과 우사기의 착지/회복 근거 확보 전 활성화 금지. 단순 동시 바운스로 대체하지 않는다.
필수 아트: 우사기 지면 접촉/공중/착지/복귀, 하치와레 관찰/반응/복귀. 세 인물 구도의 크롭을 둘만의 원작 장면으로 소개하지 않는다.

D 특훈 보고 — 하치와레와 라코
상태: 공식 관계 확인, 장면 동작 미확인으로 보류.
트리거: 사용자가 연습 요약을 닫은 뒤 휴식 영역에서 선택. 점수와 토벌 서열을 연결하지 않는다.
각색 시퀀스: 하치와레가 성과를 보여주는 자세 → 라코의 중립적인 주목 → 복귀. 고개 끄덕임/박수/머리 만지기는 아직 증거 없음. 칼 휘두르기 금지.
필수 아트: 양쪽 정확한 시선과 간격, 라코 망토/검의 비활성 실루엣, 상대 반응과 복귀. 332화 실제 장면 관찰 우선.

E 돌봄을 받는 시사 — 치이카와와 시사
상태: 공식 삼인 간호 사건의 이인 각색 후보, 휴식 컨셉만 보존하고 구현 보류.
트리거: 명시적 휴식 선택. 오답/이탈/연속 실패로 시사를 아프게 만들지 않는다.
각색 시퀀스: 치이카와가 옆에서 조용히 주목 → 시사가 쉬는 자세 → 각자 복귀. 투약/체온 측정/담요 건네기 등은 확인하지 못했으므로 넣지 않는다. 병약함을 시사의 상시 성격으로 만들지 않는다.
필수 아트: 252화 양쪽 모습과 회복, 눕는 자세가 실제 존재하는지 확인, 비접촉 거리. 현재는 자세도 미확정.

치이카와–라코: 관계 확인, 개별 특훈/노래 시선 추가 연구 대기.

하치와레–라코: D 보류.
하치와레–시사: 252화 사건 확인, E와 같은 사유로 별도 구현하지 않음.

캐릭터별 출연량을 맞추기 위해 미확인 쌍을 채우지 않는다. 출현 확률·친밀도·좋아함 점수는 원작 자료로 산출하지 않았다.

예약과 취소 설계
이하 전부 웹 앱 설계값이며 원작 빈도나 성격 수치가 아니다.
기본값은 자동 실행 꺼짐. 캐릭터별 쌍 참여 허용, 전체 중지, 쌍별 숨김을 제공한다. 여기서 동의는 사용자의 UI 선택과 두 캐릭터 상태의 참여 가능 판정이지 허구 인물의 실제 의사 추정이 아니다.
한 번에 활성 쌍은 최대 1개. 두 캐릭터, 양쪽 도착 위치, 두 이동 경로, 장식 소품을 하나의 예약으로 원자적으로 확보한다. 한쪽만 잠그고 대기하지 않는다. 고정 순서로 확보하고 하나라도 실패하면 전체 해제한다. 한 캐릭터는 하나의 개별/쌍 동작만 소유한다.
상태 순서: 후보 → 두 참여자 예약 → 안전 경로 확인 → 접근 → 준비 → 짧은 상호작용 → 복귀 → 예약 해제 → 쿨다운. 모든 단계에 취소 분기. 준비 시점에 두 캐릭터와 영역을 재확인한다. 예약 ID와 세대 번호가 맞지 않는 지연 완료 신호는 무시한다.
도착 전 누가 집히거나 숨겨짐/비활성/페이지 전환/학습 재개/창 크기 변경/탭 숨김/모션 줄이기 적용/사용자 중지가 발생하면 양쪽 모두 취소한다. 소품을 지우고 안전한 중립 위치에 정지하며 예약을 즉시 해제한다. 사라진 상대를 쫓아가거나 장면을 나중에 재생하지 않는다. 탭 복귀 때 밀린 동작 없음.
접근할 빈 공간이 없거나 보호 영역을 통과해야 하면 취소한다. 상대가 거부 상태면 밀어내기/재시도 추격/불쾌한 표정 없음. 가까이 두었다고 강제 접촉하지 않는다. 캐릭터 드래그를 상대 몸 위에 놓는 것은 쌍 동작 실행 동의가 아니다.
제안 쿨다운: 성공한 동일 쌍 120초, 각 참여자 60초, 실패한 제안 재검토 30초. 사용자 중지/숨김/거절 뒤에는 시간이 지나도 자동 재개하지 않고 다음 명시적 요청까지 대기한다. 예약 도착 제한 3초, 장면 제한 4초는 안전 상한 후보이며 원작 측정값이 아니다. 이 숫자는 QA 결과로 조정한다. 사용자 입력이 오면 제한시간을 채우려고 기다리지 않는다.

학습 방해 방지
정답 영역, 문제 카드, 선택지, 입력창, 발음/음성 버튼, 진행/뒤로 버튼, 스크롤 경로는 보호 영역이다. 캐릭터 몸뿐 아니라 꼬리/귀/망토/소품/그림자와 경로까지 침범 금지. 화면에 안전한 두 자리가 없으면 캐릭터 축소나 화면 가리기로 해결하지 않고 실행하지 않는다.
문제 읽기·답 입력·IME 조합·정답 확인·오디오 재생 중에는 시작 금지. 시작 후에도 해당 이벤트가 생기면 즉시 취소한다. 소리는 기본 없음. 점수, 학습 기록, 정답 표시, 포커스, 스크롤 위치를 변경하지 않는다. 장식 애니메이션이 키보드나 포인터를 가로채지 않는다. 동작 종료를 다음 문제 이동의 조건으로 삼지 않는다.
모션 줄이기에서는 움직이는 쌍을 실행하지 않고 기존 정지 개별 캐릭터를 유지한다. 장면마다 스크린리더 알림을 반복하지 않는다. 수동 제어의 이름과 현재 상태는 읽을 수 있어야 한다.

1 양쪽 개별 동작 QA 통과 기록과 쌍 전용 아트 존재.
2 시작·상호 반응·회복 근거 구분; 미관찰 구간은 각색 표시 또는 보류.
3 모든 상태에서 집기·숨김·학습 재개·탭 숨김 취소 후 예약과 소품 0.
4 같은 캐릭터를 요구하는 두 제안 경쟁에서 한 개만 실행.
5 늦은 완료 이벤트가 새 장면이나 캐릭터 위치를 덮어쓰지 않음.
6 좁은 화면/확대/리사이즈에서 보호 영역 비침범, 경로 실패 시 무동작.
7 빠른 문제 이동에도 답안/점수/포커스/음성 영향 0.
8 모션 줄이기 및 전체 중지 즉시 반영.
9 세 번 반복 재생에서 역할 차이와 취소 자세가 어색하지 않은지 시각 확인.
10 위 검증을 통과해도 사용자에게 승인된 범위 안에서만 쌍 활성화.
