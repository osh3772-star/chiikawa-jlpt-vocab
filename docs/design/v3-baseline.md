# 영상 근거 기반 캐릭터 구현 — v3

영상 후보 13개이며 정식 원작동작 활성은 0입니다. 모몽가만 검토된 파생 정지 자세 한 장과 작성한 웹 이동 경로의 제한 미리보기를 제공합니다. 날갯짓/이륙/착지/원작 속도·궤적을 구현한 것이 아닙니다. 기존 치이카와4키포즈 베타는 창작 초안으로 별도 표시합니다.

6종 개별 표시/모두 표시/모두 숨김 및 별도 일시정지, 모바일 스크롤 dock, 독립 선호저장, 숨김시 캡처/짝/공중 정리를 구현했습니다. 모몽가 손상6그림은 정상 idle 정지 그림으로 대체하고 원본은 보존했습니다.

공개 JSON은 필요한 관찰 사실·출처URL·표본시각·검토범위만 보존한 정리본입니다. 개인 제공 정지이미지, 원본 영상, 브라우저 캡처, 내부 작업기록/작업환경 경로는 배포하지 않습니다. 표본시각을 CSS 시간으로 변환하지 않습니다. 아트의 공식성/라이선스 승인을 주장하지 않습니다.

새 배경 선택 기능과 짝 행동은 아직 구현하지 않았습니다. 배경 조사는 후속 설계 자료이며 코드 구현 완료를 뜻하지 않습니다. docs/index.html 배포본과 원본 단어 데이터는 이 변경에서 수정하지 않습니다.

로컬 실행: python build_html.py. 검수: python build_preview.py 이후 node --test tests/*.test.mjs 및 python -m unittest discover -s tests -p 'test_*.py'.

데스크톱 실제 QA: 제한 미리보기 자동종료시 카드 위치 유지, 카드 미침범, 빠른재실행/닫기/숨김, 기본actor 중복방지·복원, 일시정지 정지표시, 학습상태 유지 통과. 모바일 미리보기/OS 동작줄이기는 실제환경 추가검증 대상입니다.
