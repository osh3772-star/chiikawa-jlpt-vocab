# 모몽가 제한 미리보기 (v3 작업본)

- 화면의 **모몽가 제한 미리보기** 버튼으로만 실행하며 저장/자동실행하지 않습니다.
- `영상 자세 참고 + 웹 이동 연출`: EP27에서 관찰된 공중 펼침 자세를 참고한 파생 PNG 한 장입니다. 원작 픽셀컷아웃이나 원작 비행 동작/궤적 재현이 아닙니다.
- 검토된 R3 PNG를 바이트 그대로 보존합니다. 초기 1회 등비 크기 설정 후 translation만 사용하며, 몸회전/미러/부위변형/프레임루프/날갯짓/이륙·착지는 없습니다.
- 1.8초는 작성한 웹 UX 시간이며 영상 시각을 변환한 속도가 아닙니다. 빈 문서흐름 무대의 **전체 이동 영역**과 학습/입력 영역 충돌을 검사합니다. 공간이 없으면 실행하지 않습니다.
- 재생 중 기본 모몽가 actor를 숨겨 중복 표시하지 않습니다. 끝/닫기/숨김/스크롤/창변경/포커스이탈/일시정지 시 새 착지 없이 제거하고 현재 표시 설정에 맞춰 복원합니다.
- 일시정지 또는 동작 줄이기 상태에서 명시적으로 버튼을 누르면 **정지 자세만** 표시합니다. 이 정지 미리보기는 자동 종료되지 않으며 닫기/Escape/선호 변경/수명주기 취소로 종료합니다. 재개만으로 자동 이동하지 않습니다.
- 이미지 로드 대기 중 숨김/취소는 세대 토큰으로 무효화합니다. 실패하면 미리보기만 생략합니다.
- `momonga.json` 및 `review/` 문서/이미지 해시와 현재 evidence registry의 승인 범위를 빌드 시 교차 검증합니다. 검토문서 편집이나 enabled 플래그 하나로 정식 동작을 켤 수 없습니다.
- 승인 범위: LIMITED_PREVIEW_BODY_ONLY / LIMITED_PREVIEW_TESTING. 원작 동작 registry 활성 수는 여전히 0입니다. 안전/접근성 실브라우저 검수 결과는 별도로 기록해야 합니다.

코드: `momonga-preview.js` (경로/비동기 제어), `integration.js` (버튼/무대/생활주기), `pet-engine.js` (단일 actor 독점 표시), `limited_preview.py` (검토/아트 검증).

무대는 초기에는 접혀 있습니다. 명시적인 시작으로 펼친 뒤에는 자동 완료/취소/숨김에서도 공간을 유지하여 학습 카드가 갑자기 이동하지 않습니다. **미리보기 무대 닫기**를 누를 때만 문서 공간을 접습니다. 이미지 숨김과 무대 접기는 별개입니다.
