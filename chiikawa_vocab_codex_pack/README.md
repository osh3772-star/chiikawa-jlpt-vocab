# 치이카와 단어장 — Codex 에셋 + 인터랙티브 캐릭터 패키지

기존에 구현한 단어장에 3종 캐릭터 움직임을 추가하는 **3~6단계 통합 패키지**입니다.

## 들어 있는 것
- 캐릭터 3종 × 8개 = **24개 투명 PNG 동작 이미지**
- 캐릭터 원본 생성 시트 3개
- 파스텔 하늘·들판 배경 PNG/WebP 및 꽃·별·구름 SVG
- 프레임/이벤트 JSON, 브라우저용 JS·CSS 모듈
- 독립 실행 가능한 예제 단어장 (`demo/index.html`)
- Codex에게 그대로 전달할 작업지침 (`CODEX_INSTRUCTIONS.md`)

## 실행하기
Python이 설치된 PC에서 압축을 해제한 폴더를 터미널로 연 뒤:

```powershell
py -m http.server 8000
```

브라우저에서 `http://localhost:8000/demo/`를 엽니다.

## 기존 프로젝트에 적용하기
1. ZIP을 단어장 프로젝트 내부의 참고 폴더로 압축 해제합니다.
2. Codex에서 **아래 한 줄**을 실행 지시로 전달합니다.

> 이 프로젝트의 `chiikawa_vocab_codex_pack/CODEX_INSTRUCTIONS.md`를 읽고, 3~6단계를 기존 단어장 기능을 보존하면서 구현해. 포함된 PNG/WebP 이미지와 순수 JS/CSS 모듈을 활용하고, 실제 브라우저에서 검사한 다음 수정 내역과 테스트 결과를 보고해.

3. 예제 `demo/`는 기존 프로젝트에 덮어쓰지 마세요. Codex가 실제 기존 코드에 필요한 부분만 통합해야 합니다.

## 구분할 사항
이 에셋은 프로젝트를 위해 **새로 생성된 캐릭터 일러스트**입니다. 공식 치이카와 제작사에서 제공하는 원본 파일이나 공식 애니메이션 시트가 아닙니다. 개인 프로젝트 사용을 전제로 묶었으며, 외부 재배포 권한을 보장하지 않습니다.

### 참고
- HTML 단독 환경이라면 `file://`로 열지 말고 서버를 실행하세요.
- 캐릭터를 잡는 연출은 드래그/낙하 물리이며 뼈대 기반의 실제 리깅은 아닙니다.
- 생성된 이미지에는 일부 자세 불일치가 있으므로 연속 프레임 애니메이션 품질에는 한계가 있습니다.
