# 치이카와 · 하치와레 · 우사기 에셋 묶음

이 ZIP에는 **치이카와(chiikawa), 하치와레(hachiware), 우사기(usagi)**만 들어 있습니다.

- `chiikawa/`: 기존 제작한 투명 PNG 8개, 스프라이트 시트, 미리보기, 설정 파일
- `hachiware/`: 기존 제작한 투명 PNG 8포즈와 호환용 별칭 PNG 5개, 시트, 미리보기, 설정 파일
- `usagi/`: 재생성한 시트와 시트에서 분리한 투명 PNG 8개(390×520), 설정 파일

각 캐릭터의 PNG는 `캐릭터명/assets/characters/캐릭터명/`에 있습니다.
원본 시트도 각 캐릭터의 폴더에 보관했습니다.

**참고:** 이 이미지는 연속 동작 애니메이션이 아닌 정적 동작/표정 에셋입니다. 하치와레의 호환용 5개 파일은 개별 연속 프레임이 아니라 기존 포즈의 별칭입니다.
