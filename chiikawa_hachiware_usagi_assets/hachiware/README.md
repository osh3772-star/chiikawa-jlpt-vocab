# Hachiware asset pack / 하치와레 에셋팩

- 8개 서로 다른 원작 특징 기반 생성 포즈: idle, wave, happy, encourage, guitar, camera, reaction, sasumata
- 390×520 투명 RGBA PNG, 경로: `assets/characters/hachiware/*.png`
- 원본 2×4 스프라이트 시트: `hachiware_8pose_original_sheet.png`
- JPG 프리뷰: `HACHIWARE_PREVIEW.jpg` (체커보드 배경은 미리보기에만 있음)
- 기존 1.1.0 프로젝트와 파일명 호환: blink, walk-a, walk-b, grabbed, landing 5개 별칭 PNG
  - blink = happy, walk-a = wave, walk-b = encourage, grabbed = reaction, landing = idle
  - **주의:** 위 5개는 별칭 이미지이며 실제 걷기/잡힘 모션 애니메이션을 개별 생성한 것은 아닙니다.
- 기존 `animation-config.json`의 하치와레 8가지 기본 파일명을 그대로 유지할 수 있습니다.
- 생성된 팬아트 형태의 이미지로, 공식 원본 에셋이 아닙니다.
