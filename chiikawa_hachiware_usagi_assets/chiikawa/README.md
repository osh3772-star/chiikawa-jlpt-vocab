# Chiikawa (ちいかわ) — 8-pose assets

## Included poses (390 x 520 transparent PNG)

1. `idle.png` — 기본 서기
2. `wave.png` — 소심한 인사
3. `happy.png` — 정답 기쁨
4. `encourage.png` — 용기 내기
5. `cry.png` — 울먹임
6. `reaction.png` — 놀람/당황
7. `sasumata.png` — 토벌 도구 들기
8. `weeding.png` — 풀 뽑기

`chiikawa_8pose_original_sheet.png` is the full source sheet.
`chiikawa-config.json` lists the eight character poses.

These are static different character poses, not sequential animation frames. All individual PNGs use RGBA transparent backgrounds.

Character profile references:
- https://www.chiikawaofficial.com/characters/
- https://www.anime-chiikawa.jp/chara.html
